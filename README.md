## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### Production Build
```bash
npm run build
```
The output will be generated in the `dist/` directory.

### Serving on Android (Termux / Node server)
If serving from an Android device or Linux container:
```bash
# 1. Install dependencies & build
npm install
npm run build

# 2. Preview or serve static build
npx serve -s dist -l 5173
# or directly run vite dev exposed to network
npm run dev -- --host
```
